## 🚀 طريقة الرفع على GitHub وتفعيل GitHub Pages

المشروع مصمم كصفحات HTML ثابتة 100% بدون أي أدوات بناء (Zero Build Tools)، ومساراته كلها نسبية `./`:

1. قم بعمل Push للملفات إلى مستودع GitHub:
   ```bash
   git add .
   git commit -m "إطلاق متجر الشرقاوي لمنتجات الفلاحي"
   git push origin main
   ```
2. افتح صفحة المستودع على GitHub واضغط على **Settings**.
3. من القائمة الجانبية، اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - Source: اختر **Deploy from a branch**.
   - Branch: اختر **main** والمسار **/ (root)**.
   - اضغط **Save**.
5. خلال دقيقة واحدة، سيظهر لك الرابط الحي لموقعك مجانًا على نطاق GitHub Pages.

## 📱 مميزات التصميم والتقنية

- **ثنائي اللغة كامل (عربي افتراضي + إنجليزي):** مع دعم RTL و LTR وتبديل فوري وحفظ الخيار في `localStorage`.
- **ألوان مستوحاة من الريف الفلاحي الأصيل:** كريمي، عاجي، أخضر زيتوني داكن، وذهبي زبدي.
- **خلفية فيديو للهيرو بدون حجب أو تغييم:** يظهر الفيديو بألوانه الطبيعية النقية مع بطاقة نصية كريمية مستقلة.
- **تواصل وطلب عبر واتساب فقط:** متوافق تمامًا مع سلوك الشراء في السوق المصري، وبدون أي سلات أو بوابات دفع معقدة.
- **متجاوب 100%:** مختبر على كافة الشاشات والموبايل (360px و 390px فما فوق).
- **SEO و Accessibility:** وسوم Schema.org للمتجر والمنتجات، وOpen Graph، ومراعاة `prefers-reduced-motion`.
